## 下一輪（尚未開 OpenSpec change）

主題：**整碟級掃描安全網**，不是再做一套 Linux／Mac 原生程式。

Chrome／Edge 走 `showDirectoryPicker`；Firefox／Safari 走 `webkitdirectory`。路徑已用 `/`。三個桌面系統會一起踩同一塊：記憶體與「選到磁碟根」。

建議範圍（實作前先 **propose**）：

1. **硬上限**：檔案數（或記憶體／節點數）到門檻就停或改為摘要模式，不能只警告。
2. **完成時不要整棵樹 structured clone 到 UI**；主執行緒只留目前鑽取層或虛擬化所需資料。
3. **系統目錄策略**：權限被拒已計 skipped；要不要主動跳過 Windows `Windows`、macOS `/System`、Linux `/proc` `/sys`，要寫進 spec。
4. **Fallback**：整碟 `webkitdirectory` 仍可能在選完資料夾當下爆掉；硬上限若只做在 Worker 裡救不了這條。
5. **跨平台驗證**：Win／Mac／Linux 各測小資料夾與盡量大的家目錄；不要把掃 `/` 當成功標準。

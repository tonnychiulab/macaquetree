## Why

README 把產品標題寫成 `MacaqueTree (台灣獼猴)`，並用非正式英文俗名 Formosan Rock Macaque。臺北市生物多樣性資料庫物種頁寫的是臺灣獼猴、Formosan Macaque、*Macaca cyclopis*。產品雙關名 MacaqueTree 要留，物種文案要對齊該頁。

## What Changes

- README 標題改為 `MacaqueTree`，不再括號附中文種名。
- 核心理念那句「台灣唯一的特有種猴類 —— 台灣獼猴 (Formosan Rock Macaque)」改為「臺灣獼猴（Formosan Macaque，Macaca cyclopis）」。
- 不改產品名、GitHub repo、Workers 網址、`package.json`、UI `APP_NAME`、掃描行為。
